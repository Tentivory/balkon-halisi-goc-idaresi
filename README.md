# Balkon Halısı Göç İdaresi

T.C. Tentivory Kayyumluk Makamı bünyesinde, hiç kimsenin istemediği ama birinin kurması gereken daire.

Bu yazılım, bir halının bir balkondan diğer balkona geçişini **ruhsatlandırır**. Rüzgar hızı, komşu bakışı, çay lekesi yaşı ve çamaşır ipinin diplomatik statüsü dikkate alınır. Bilimsel değildir. Ciddi görünür. İkisi de kasıtlıdır.

## Neden var?

Çünkü halılar sessizce yer değiştirir. Bir gün senin balkonundadır, ertesi gün komşunun korkuluğunda “ben buranın yerlisiyim” diye yatar. Devlet boşluğu kabul etmez. Biz de etmedik.

## Kurulum

```bash
pip install -r requirements.txt
python hali_goc.py --kat 4 --ruzgar 17 --bakis sert --leke orta
```

Bağımlılık yoktur. `requirements.txt` boş değil, felsefi olarak doludur.

## Çıktı

Program sana resmi bir göç belgesi basar. Belgeyi balkona asabilirsin. Komşu itiraz ederse dosya numarasını oku. Dosya numarası rastgeledir, itiraz da öyle.

## Copilot notu

`.github/copilot-instructions.md` içinde Copilot'a seslenildi. Cevap verirse tutanak tutulacak. Vermezse de tutanak tutulacak.

## Yasal uyarı

Bu repo hiçbir belediyeyi, bakanlığı veya çamaşır ipini temsil etmez. Halınız kaybolursa sorumluluk rüzgarındır.
